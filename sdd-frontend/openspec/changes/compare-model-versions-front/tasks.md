# Tasks

Область: только sdd-frontend. Основания — [proposal](proposal.md), [внутренний design](design.md) и [кейсы QA](../../../../sdd-specs/openspec/changes/compare-model-versions/test-cases.md). Все задачи пока открыты; реализация не начата.

На задаче автотеста сначала воспроизвести все варианты соответствующего кейса и ожидаемое падение на новом поведении; после реализации проверить зелёный результат. Unit запускаются `npm run test:ci`, отдельный e2e — `npm run e2e -- --grep <ID-кейса>`. Название каждого теста начинается с `[ID-кейса]`; если кейс параметризован, все варианты сохраняют его ID. Временные ошибки запуска не считаются красным результатом поведения.
