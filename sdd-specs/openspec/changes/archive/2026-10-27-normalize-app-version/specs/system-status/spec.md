# Spec Delta

## MODIFIED Requirements

### Requirement: API статуса системы
Система SHALL (ДОЛЖНА) предоставлять публичный, не требующий авторизации эндпоинт статуса, который возвращает признак работоспособности и версию развёрнутой сборки бэкенда.

#### Scenario: [system-status-01] Бэкенд сообщает, что он работает
- **WHEN** клиент запрашивает статус системы
- **THEN** ответ успешный (HTTP 200) в формате JSON
- **AND** поле `status` равно `ok`
- **AND** поле `version` содержит версию развёрнутой сборки

#### Scenario: [system-status-02] Версия сборки задаётся при развёртывании
- **WHEN** бэкенд запущен с версией сборки, заданной при развёртывании
- **THEN** поле `version` в ответе статуса совпадает с этой версией
- **AND** если версия не задана, поле `version` равно `dev`

#### Scenario: [system-status-05] Пробелы вокруг версии не попадают в ответ
- **WHEN** версия сборки задана при развёртывании с пробелами или переводом строки по краям
- **THEN** поле `version` содержит версию без этих пробелов
- **AND** если после удаления пробелов значение пустое, поле `version` равно `dev`
