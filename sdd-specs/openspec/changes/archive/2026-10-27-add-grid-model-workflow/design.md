# Design

## Context
Сейчас главная страница показывает только статус системы. Расширяем оба приложения из proposal.md. Статус остаётся в нижней части навигации.

## Goals / Non-Goals
Общий сквозной процесс на JSON; демонстрационные организации выбираются пользователем. Выбранная организация — атрибуция в журнале, не авторизация.

## Decisions
Контракт contracts/grid-models-api.yaml, версия 1.0.0. API синхронный, JSON camelCase, время ISO 8601 UTC, интерфейс форматирует локально.
Модель: id, name, region, ownerId, revision, publishedVersionId, versions, events. Версии неизменяемы по содержимому; состояние меняется отдельным действием. POST создания версии включает baseVersionId (null для первой), revision модели, organizationId, title и document.
Документ: {objects:[{id,name,type,voltageKv,links:[]}]}: 1–1000 объектов; тип substation/line/transformer/busbar, напряжение >0 и <=1150 кВ, ID уникальны, ссылки существуют. Проверка только структуры и ссылок, не электрических режимов. Некорректная структура JSON запроса → 400. Ошибки объектов сохраняются с черновиком и блокируют отправку.
Изменения: added/modified/removed по ID, сравнение name/type/voltageKv и множества links; сравнивается опубликованная база, включая удалённые объекты.
GET /api/organizations; GET/POST /api/grid-models; GET /api/grid-models/{id}; POST /api/grid-models/{id}/versions; POST /api/grid-models/{id}/versions/{versionId}/actions; GET /api/grid-models/{id}/versions/{versionId}/download.
Действия submit/approve/reject/publish. Любая известная демонстрационная организация может выполнить действие: это пилот процесса, не имитация контроля доступа. Комментарий reject обязателен. Проверки и переходы выполняет сервер, клиент отражает разрешённые действия. Не допускается approve с ошибками или устаревшей базой; также проверяются submit и publish. Одноразовый переход атомарен, revision увеличивается при каждой записи.
Ошибки {code,message}: 400 validation, 404 not_found, 409 conflict/invalid_transition. Для конфликта текст «Данные изменились. Обновите карточку и повторите действие.». Неизвестная организация → 400. Лимит тела 2 МБ. Запросы UI ограничены таймаутом 10 с, повторное нажатие во время записи отключено. Ошибка UI сохраняет заполненную форму.

## Развёртывание (Kubernetes)
Добавляется PostgreSQL 17, Service sdd-postgres:5432 и PVC 1Gi. API получает ConnectionStrings__GridModels из Secret sdd-grid-db; пароль — демонстрационный, перед внешним использованием заменить. Начальные данные добавляются только в пустую БД; API без состояния. Обновление не очищает БД. Для локальных команд та же строка подключения через переменную окружения. Readiness проверяет доступность БД.

## Risks / Trade-offs
Демонстрационная атрибуция не защищает от подмены организации; UI явно обозначает это ограничение. Одна опубликованная версия у модели, конфликт требует новой версии от актуальной базы. Малые документы намеренно ограничены 1000 объектами; для больших моделей нужен отдельный процесс импорта. Удаление PVC теряет данные.
